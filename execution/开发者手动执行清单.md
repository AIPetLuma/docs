# 开发者手动执行清单（AI 无法替代）

本清单用于记录必须由开发者/运营在控制台或设备上完成的遗留任务，AI 无法代替执行。

## 1. 账号与证书

- [ ] Apple Developer Program 账号可用
- [ ] App Store Connect 已创建 `ai.luma.app` 记录
- [ ] Apple App ID 开启 Push Notifications capability
- [ ] 创建 APNs Auth Key / 证书并接入 Firebase
- [ ] Google Play Developer 账号可用
- [ ] Play Console 已创建 `ai.luma.app` 应用

## 2. 签名与构建产物

- [ ] 生成 Android Upload Keystore
- [ ] 填写 `app/android/key.properties` 并确认 keystore 路径有效
- [ ] iOS 已配置签名证书与 Provisioning Profile
- [ ] 通过 Xcode Archive 或 Transporter 上传 iOS 构建
- [ ] 通过 Play Console 上传 `.aab` 构建

## 3. Firebase / FCM

- [ ] Firebase 项目已创建 Android App（`ai.luma.app`）
- [ ] Firebase 项目已创建 iOS App（`ai.luma.app`）
- [ ] 下载并放置 `app/android/app/google-services.json`
- [ ] 下载并放置 `app/ios/Runner/GoogleService-Info.plist`
- [ ] 真机验证 token 入库（`fcm_tokens`）
- [ ] 真机验证前台 / 后台 / 冷启动推送可达

## 4. 商店资料与合规

- [ ] 支持邮箱与官网 URL 已准备
- [ ] 隐私政策与服务条款已部署为公网 URL
- [ ] App Privacy / Data Safety 表单填写完成
- [ ] 年龄分级 / 内容分级完成
- [ ] 应用截图与 Feature Graphic 已上传
- [ ] 商店文案已完成并与应用内文案一致

## 5. 内测与提审

- [ ] TestFlight Internal Testing 可安装并通过核心流程
- [ ] TestFlight External Testing 提审准备完成
- [ ] Play Closed Testing 可安装并通过核心流程
- [ ] 收集首轮反馈并回填缺陷清单

## 6. 上架前最终确认

- [ ] `make p1-check` 无 blocker
- [ ] `RUN_FLUTTER_CHECKS=1 make p1-check` 通过
- [ ] 无 secrets / keystore / Firebase 私钥泄漏到仓库
- [ ] 版本号与 Build Number 已更新
